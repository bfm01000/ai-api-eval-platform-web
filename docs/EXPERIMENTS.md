# Experiments

当前没有进行中的 Benchmark 或 Model Fingerprinting 实验。

实验开始前必须完成：明确 Hypothesis 与 Objective；固定版本化 Dataset、Reference Models 和 Parameters；估算 Request Count、Tokens、Cost 与 Time；定义 Sample Size、Metrics 和对照组；保留原始响应与运行元数据。

每个候选行为特征必须分别评估 Repeatability、Separability、Robustness 和 Cost Efficiency。未完成验证的观察不得进入模型一致性评分。
